# 💵ATM Program💵

# Description
My project is a simple ATM simulator program. It allows user to check their balance, withdraw or deposit money.
The program keeps on running until you quit it or have insufficient money.

##  Features
- Deposit money into your account
- withdraw money with balance checks
- Check your current balance
- Quit the program smoothly
- Error handling for invalid inputs

# I made this program to learn the idea of automation. The idea and program is small and begineer friendly but I am hoping to 
improve later on.
